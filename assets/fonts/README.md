# Local fonts

Latin WOFF2 subsets downloaded from Google Fonts on September 7, 2026. Preserve Inter-OFL.txt and Playfair-OFL.txt when redistributing. Browser requests stay on this domain.

- Inter normal, weights 400-600, Google Fonts v20.
- Playfair Display normal, weights 500-600, Google Fonts v40.
- Playfair Display italic, weight 500, Google Fonts v40.
- Poppins normal, weights 400, 500 and 600, Google Fonts v24, downloaded November 4, 2026 for the homepage. Preserve Poppins-OFL.txt.

Sources: [Inter](https://fonts.google.com/specimen/Inter) [Playfair Display](https://fonts.google.com/specimen/Playfair+Display), and [Poppins](https://fonts.google.com/specimen/Poppins). Characters outside these subsets use the existing system fallback stack.
